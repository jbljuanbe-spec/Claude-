# Reglas de trabajo para Claude Code

- Respuestas breves, directas y sin preámbulos.
- No uses emojis, markdown innecesario ni despedidas.
- Lee primero el archivo relevante antes de modificar.
- No reescribas archivos completos si solo hay que cambiar una sección.
- No leas archivos binarios: .glb, .gltf, .geojson, .jpg, .png, .zip.
- Los datos narrativos viven en database.json. No los dupliques en código.
- Si una tarea es ambigua, haz una sola pregunta concreta antes de codificar.
- Código simple, sin abstracciones innecesarias.
- Al terminar, indica solo qué cambiaste y qué probar.
- La especificación completa del juego está en docs/ESPECIFICACION.md. Léela solo cuando el usuario lo pida o cuando necesites contexto del diseño.
